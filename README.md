# 💳 PrimeX Global Exchange

An advanced, responsive cryptocurrency and fiat currency exchange web application. This project was developed collaboratively as a final group homework assignment, focusing on modern web technologies, responsive layouts, and smooth user interactions.

## 🚀 Key Features
* **Dual Theme Engine:** Features a Cyberpunk Dark Mode and a highly unique Saffron Light Mode.
* **Responsive Grid System:** Fully optimized across all screen sizes (Mobile, Tablet, and Desktop views).
* **Interactive UI/UX:** Built with smooth 3D animations, interactive hover effects (such as card-flip components), and custom transitions.
* **Live Exchange Tools:** Includes an interactive online conversion calculator for instant currency calculations.

## 🛠️ Tech Stack & Architecture
* **Structure:** HTML5 (Semantic elements for strict web structure)
* **Styling & Frameworks:** CSS3 (Advanced custom variables, keyframe animations, Flexbox, and CSS Grid) & Bootstrap 5
* **Interactivity:** Vanilla JavaScript (ES6+ DOM manipulation and core calculation logic)
* **Design & Assets:** Figma for prototyping, FontAwesome 5 icon toolkit via CDN

## 📦 Git & Deployment Workflow
Our team follows an organized Git GitFlow branching strategy to prevent merge conflicts and ensure safe website deployment:
1. `main` branch is kept clean and acts as the official deployment production state.
2. Feature updates and visual stylings are tested in isolated local branches before merging.
3. Live static web hosting is automatically processed and deployed via **GitHub Pages**.
