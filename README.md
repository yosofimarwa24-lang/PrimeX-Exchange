# 💳 Primex Global Exchange

An advanced cryptocurrency and fiat currency exchange web application developed collaboratively as part of a team project.

## 🚀 Key Features
* **Dual Themes:** Cyberpunk Dark Mode & Saffron Light Mode.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
* **Interactive UI:** Smooth 3D animations and transitions.
* **Online Calculator:** Live conversion calculator for currencies.

## 🛠️ Tech Stack
* HTML5 / CSS3 / JavaScript (ES6+)
* FontAwesome Icons
